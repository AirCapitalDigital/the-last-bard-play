# The Last Bard: Alpha 0.1.1
*A small follow-up to 0.1.0: keyboard polish and menu fixes.*

## Quality of life
- **Arrow keys everywhere**: the death screen, the loadout screen and the pause menu's Run / Settings / Dev tabs can all be reached and walked with the arrow keys.
- On the loadout screen, left and right now walk the College / Companion / Pet / Crescendo row instead of jumping to BACK.
- The lute's "Crescendo ready" glow is now a small soft pulse in the colour of your equipped Crescendo's rarity.

## Fixes
- Pause menu: "Unlocked this run" is now a 3-wide grid that scrolls instead of running off the right edge, and weapons and upgrades sit in 4-wide grids.
- All unlock pop-ups (pets included) are now the same size.
- Pause menu tabs no longer trap the arrow keys.
