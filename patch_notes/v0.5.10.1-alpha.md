# The Last Bard: Alpha 0.5.10.1
*Getting ready for the stores.*

## Changes
- **Developer controls are no longer in the menus.** The developer switch is gone from Settings, and the ` key no longer turns them on. They were only ever for testing, and runs played with them never counted on the leaderboard.

## Hotfix
- **"Pick a card with" now covers the Endless / Loot Mode choice too,** so mashing the Crescendo key when it appears never picks one by accident.
- **A new home for the game: [thelastbardgame.com](https://thelastbardgame.com).** The patch notes now live there, and the game's patch notes links open it.
- **A support address:** support@thelastbardgame.com, also shown on the Leaderboard page beside "Report a problem".
- **"Share anonymous run results" off now stops everything.** With it off, the game no longer sends its crash and performance logs either.
