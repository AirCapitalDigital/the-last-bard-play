# The Last Bard: Alpha 0.5.14.3

## Changes
- **Stalacpipe Organ, redrawn:** real crystal stalactites fall with a growing shadow, shatter into shards and ring out like organ pipes.
- **The Ember skin is card art now:** outside the Crucible it dresses your cards only; weapon icons, tiles and attacks keep their own colours.
- Crucible climbs no longer land on the run leaderboards.
- Skipped songs are counted (with run results, when sharing is on) so we can see which songs players like least.
