# The Last Bard: Alpha 0.5.7.0 "Second Wind"
*The far end of a run grows teeth.*

## Changes
- **New surprises late in a long run.** Those who go the distance will find a few new things waiting, and some old ones hit harder.
- **Easier to read under pressure.** A few late-game moments now show what is happening more clearly, including where your damage is landing.

## Fixes
- **A steadier gear menu.** Hovering a relic or charm with a long description no longer stretches the gear menu across the screen or makes it flicker between sizes (desktop and browser).
