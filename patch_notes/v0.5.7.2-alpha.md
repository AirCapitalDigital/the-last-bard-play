# The Last Bard: Alpha 0.5.7.2
*Clearer leaderboards.*

## Changes
- **Every fall counts.** Most deaths now counts every time you fall in a run, including the falls a Revive brought you back from. Runs from older versions still count once.
- **Ranked playtime.** The playtime board is now called Ranked playtime, and the Totals boards say they count ranked runs only (not runs with developer controls or changed settings), so it is clear why it can differ from Time played in your Journal.
